# Actividad 12 — Privacidad por diseño
1. **¿Qué problemas identificas?** Se están pidiendo demasiados datos personales muy íntimos que no sirven para la operación principal (salario, estado civil, ocupación), lo que incrementa el riesgo sin necesidad.
2. **¿Qué principio de privacidad se está ignorando?** El de **Minimización**.
3. **¿Qué preguntas realizarías antes de aprobar el diseño?** ¿Por qué necesitamos exactamente cada uno de estos campos y hay forma de quitarlos?
4. **¿Qué datos eliminarías?** La dirección exacta, ocupación, salario, estado civil y fecha de nacimiento.
5. **¿Qué datos requerirían una justificación adicional?** El salario, solo si se usara para un crédito con autorización especial del usuario.
6. **¿Cómo aplicarías privacidad por defecto?** Configurando el sistema para que pida lo mínimo indispensable por regla general y bloqueando accesos innecesarios.
